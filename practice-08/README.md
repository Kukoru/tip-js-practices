## Полученный результат

Приложение загружает задачи и категории с учебного API. Реализованы создание, редактирование, смена статуса и удаление задач. Данные хранятся в памяти сервера: при его перезапуске они восстанавливаются к исходному набору (12 задач). Интерфейс отображает состояния загрузки, ошибки и пустого списка.

## Архитектура

- **api-client.js**: транспорт (fetch, обработка статусов, JSON, тайм-аут, AbortController).
- **task-api.js**: предметный API (маршруты, проверка схемы ответа).
- **useTaskData.js**: хук, который управляет состоянием (snapshot, status, error, pending) и вызывает методы API.
- **App.jsx**: владелец фильтров и редактируемой записи, связывает компоненты.

**Отличия от ПР7**: данные больше не хранятся в памяти React (в `useState`), а запрашиваются с сервера. Состояние `snapshot` обновляется после каждого GET. Эффекты (`useEffect`) используются для загрузки и отмены предыдущих запросов через `AbortController`.

## Загрузка и изменения

- **Старые ответы**: в хуке используется `requestSeq` (счётчик запросов) и `isMountedRef`. Если приходит ответ от старого запроса (номер не совпадает) или компонент размонтирован, он игнорируется.
- **Повторная мутация**: блокируется через `mutationInProgress` (ref). Если мутация уже идёт, повторный вызов возвращает `false`.
- **Ошибки**: ошибка GET сохраняется в `error` и показывается как «Не удалось обновить список». Ошибка мутации сохраняется в `mutationError` и показывается как «Изменение не подтверждено». Они не смешиваются.
- **Черновик формы**: при ошибке сохранения форма не очищается. Пользователь может исправить данные и повторить попытку.

## Контрольные вопросы

1. **Чем `fetch` не отклоняет Promise при 404?** Это успешный HTTP-ответ, статус проверяется вручную.
2. **Почему 204 нельзя разбирать как JSON?** Нет тела.
3. **Почему `useEffect` нужен cleanup?** Чтобы отменить запрос при размонтировании или смене зависимостей.
4. **Зачем `useRef` для флага мутации?** `useState` вызывает ререндер, а флаг нужен сразу, без задержки.
5. **Что произойдёт, если не отменять старый запрос?** Старый ответ может перезаписать новые данные (гонка).

## Вывод

Освоены `useEffect`, `useRef`, `useCallback`, отмена запросов и обработка ошибок при работе с API. Исправлены ошибки в хуке, связанные с передачей сигнала отмены и возвратом промисов. При замене учебного API на собственный сервер потребуется изменить только `baseUrl` в `.env` и, возможно, доработать схему проверки ответа, если она изменится.
