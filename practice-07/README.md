Проверки: `npm test` (28 тестов). Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Результат
Приложение отображает список задач с фильтрами. Реализовано создание, редактирование, переключение статуса и удаление задач. Статистика пересчитывается автоматически. Данные хранятся в памяти (при перезагрузке сбрасываются).

## Компоненты и состояние
- **App.jsx**: владелец `tasks`, `filters`, `editingId`. Вычисляет `visibleTasks` и `stats` при рендере. Передает данные вниз через props, обрабатывает действия через колбэки.
- **TaskStats.jsx**: принимает `stats` и отображает сводку.
- **TaskFilters.jsx**: управляемые поля для фильтрации.
- **TaskList.jsx**: принимает отфильтрованные `tasks`, рендерит `TaskItem` или пустое состояние.
- **TaskItem.jsx**: карточка задачи.
- **TaskForm.jsx**: хранит локальный черновик (`draft`) и ошибки (`errors`). Вызывает `validateTaskDraft` и `onSave`.

## Индивидуальный вариант
**Начальный фильтр:** `completed: 'false'` (В работе).
**Сценарий:** Завершить видимую задачу. Она исчезает из выборки, статистика меняется (выполненных +1, в работе -1).
